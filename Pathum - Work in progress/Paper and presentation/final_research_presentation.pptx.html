Wi-Fi 7: The Next Generation

Key Features

  • 320 MHz Channels - Ultra-wide bandwidth
  • 4096-QAM (4K-QAM) - Higher spectral efficiency
  • Multi-Link Operation (MLO) - Multi-band transmission
  • Extremely High Throughput (EHT)

Target Applications

  • Extended Reality (XR/AR/VR)
  • 4K/8K Video Streaming
  • Cloud Gaming
  • Industrial IoT

Challenge: Increased complexity introduces new attack surfaces that traditional security approaches cannot address

MLO Innovation:
Single device transmits/receives simultaneously across 2.4, 5, and 6 GHz bands

Multi-Link Operation (MLO)

Operating Modes

STR Mode (Simultaneous Transmit Receive)
Links operate asynchronously and independently
Non-STR Mode
Links synchronized - all must be free for transmission

Link Types

  • Primary Link: Association, auth, control traffic
  • Secondary Links: Bandwidth aggregation, latency reduction

The Complexity Problem

  • Multiple backoff counters to coordinate
  • Packet steering decisions
  • Dynamic link allocation
  • Real-time synchronization

Result: New attack surface at MAC-layer coordination logic

The Security Challenge: Backoff Manipulation

Backoff Mechanism Vulnerabilities

1
CSMA/CA uses random backoff timers
2
MLO adds multiple backoff counters
3
Backoff compensation synchronizes
4
Creates "free ride" phenomenon
5
Exploitable by attackers

Free Ride: Link transmits without completing full backoff because another link's timer expired

Backoff Overflow: Repeated compensations cause counter errors and fairness collapse

Problem Statement

Wi-Fi 7's Multi-Link Operation (MLO) promises ultra-low latency, but it still uses the old, trust-based "backoff" system. A malicious device can exploit this by manipulating its backoff counter to "cheat" the system.

This Creates:

  • Denial of Service (DoS)
  • Time-based Attacks
  • Fairness Collapse

Our Problem:

Identify anomalies in different states, create a threat prediction and prevention system for this new, unstudied attack vector.

Threat Model: Backoff Manipulation Attack

Attack Formula

Backoffnew = Backoffcurrent + Bias

Attack Types

Positive Attack (+100 to +10000)
Inflates contention window → Self-starvation → Throughput collapse
Negative Attack (-100 to -10000)
Decreases contention window → Aggressive access → Fairness degradation

Attack Execution

  • Attacker listens on busy link
  • Pauses own backoff counter
  • Counter expires on clear link
  • Induces backoff overflow
  • Gains perpetual "free rides"
  • Dominates channel access

GCN Model Architecture

Why GCN?

  • Captures temporal relationships
  • Learns sequential patterns
  • Effective for subtle signatures
  • Graph structure = network topology

Architecture

  • 2-layer GCN
  • Input: 256-window graph
  • Nodes: 16 features each
  • Edges: t ↔ t+1 connections

Output:

  • Binary Classification
  • 0 = Normal Traffic
  • 1 = Attack Detected
  • Confidence Score
Dataset:
~284 scenarios (50% normal, 50% attack)
Pilot: 29 | Extended: 255
