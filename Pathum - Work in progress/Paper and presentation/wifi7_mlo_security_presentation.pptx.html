Multi-Link Operation (MLO)

What is MLO?

A single Multi-Link Device (MLD) can transmit and receive simultaneously across multiple frequency bands:

  • 2.4 GHz band
  • 5 GHz band
  • 6 GHz band

Operating Modes

  • STR Mode: Asynchronous, independent links
  • Non-STR Mode: Synchronized links

Link Types

Primary Link: Anchor for association, authentication, and control traffic. Backward compatible with legacy devices.
Secondary Links: Dedicated for MLDs to achieve bandwidth aggregation and latency reduction.

The Security Challenge

Backoff Mechanism Vulnerabilities

Wi-Fi 7's MLO introduces backoff compensation to synchronize multiple backoff counters:

  • Improves efficiency across links
  • Creates "free ride" phenomena
  • Can lead to backoff overflow

Free Ride: A link transmits without completing its full backoff because another link's timer expired

Backoff Overflow: Repeated compensations cause counter errors, creating fairness challenges

Critical Insight: These "performance anomalies" can be weaponized as sophisticated DoS attacks

GCN Model Architecture

Why GCN?

  • Captures temporal relationships in network data
  • Learns sequential patterns across time windows
  • Effective for detecting subtle attack signatures
  • Graph structure naturally represents network topology

Model Design

  • 2-layer GCN architecture
  • Input: 256-window temporal graph
  • Nodes: Time windows with 16 features
  • Edges: Adjacent time connections (t ↔ t+1)

Output:

  • Binary Classification
  • 0 = Normal Traffic
  • 1 = Attack Detected
  • Confidence Score
Training Dataset:
~284 scenarios (50% normal, 50% attack)
Pilot: 29 | Extended: 255

Limitations & Threats to Validity

Technical Limitations

  • Simulation Fidelity: Results may not perfectly transfer to physical hardware due to RF interference, hardware variations
  • Dataset Scale: 284 scenarios sufficient for proof-of-concept, but limited diversity
  • Attack Scope: Focused on backoff manipulation only

Evidence Quality Notes

  • Documentation Drift: Some docs contain outdated status info
  • Version Claims: Narrative describes behavior changes; artifacts may be duplicated
  • Dataset Counts: Minor discrepancies (255 vs 257) in extended dataset
Transparency: We report these limitations to maintain research integrity and guide future work
