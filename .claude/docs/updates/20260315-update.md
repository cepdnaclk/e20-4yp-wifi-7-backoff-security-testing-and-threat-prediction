## New ADRs Added
| ADR | Title | Key Decision |
|-----|-------|-------------|
| ADR-WP13-01 | 30% threshold for dynamic segment labeling | 30% not 50% — more sensitive to early attack onset |
| ADR-WP13-02 | Wider/deeper GCN architecture for v4 | hidden=128, 3 layers vs v3's hidden=64, 2 layers |
| ADR-WP13-03 | Strict seed pool partitioning for no-leakage | Train/val/test pools strictly disjoint |
| ADR-WP13-04 | nap5-6 held out as topology generalization test | nap5/6 only in test split, not training |
| ADR-WP13-05 | Bias diversity in training set | Bias ±1000,±2000,±5000 in train; v3 used ±5000 only |
| ADR-WP13-06 | Static/Dynamic folder separation | Folder structure determines labeling strategy |
| ADR-WP13-07 | Synthetic stitching for dynamic training data | Stitching from static sources gave 1,852 vs 528 planned dynamic files |
